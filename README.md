# Yara Portfolio

Next.js portfolio with a dark purple theme, responsive layout, scroll reveal animations, hover interactions, and progress bar.

## Run
1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000.

## Edit
- `data/portfolio.js`: All names, text, skills, projects, experience, contact links.
- `app/globals.css`: Colors, layout and animations.
- `app/page.js`: Page structure and sections.
- Add a CV PDF to `public/yara-cv.pdf` and set `cv: '/yara-cv.pdf'` in `data/portfolio.js`.

The project names are based on the discussed CV, but project descriptions and the experience entry are editable draft placeholders; verify them against the original CV before submitting. This is a close stylistic recreation of the supplied TikTok reference, not a pixel-exact copy.
